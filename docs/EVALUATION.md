# 从工程测试到真实效果验证

这里是待执行协议，不是已完成的实验结果。先使用合成材料和受控知识库。

## 最小功能验收

| 场景                | 可观察结果                               |
| ------------------- | ---------------------------------------- |
| 空知识库分析        | 无引用，检索 Token 为 0                  |
| 导入相关资料        | 数据库存有正文与向量，报告有可展开的引用 |
| 无关检索            | 不强行返回低于阈值的片段                 |
| 删除资料            | 下一次不再引用被删除片段                 |
| 保存/编辑偏好       | 刷新、重启后可读取修改结果               |
| 不勾选摘要          | 不增加会话记忆                           |
| 勾选摘要            | 保存未验证摘要，下一次读取数量增加       |
| 旧偏好冲突          | 当前明确输入优先，人工检查输出           |
| 未知引用 ID         | 拒绝结果，不保存本次摘要                 |
| 公开模式/错误口令   | 私有 API 拒绝，不能读写                  |
| 模型/Embedding 失败 | 显示错误，不伪造成功结果                 |

## RAG 对照实验

准备至少 20 个查询并人工标注相关片段，包含同义词、混合主题、无答案和指令注入。
固定模型、Prompt、知识库版本与问题集合，对比无 RAG 和有 RAG。相同输入重复运行并记录波动，不只挑成功案例。

- Recall@4：标注相关片段中被前 4 条检索覆盖的比例。
- Precision@4：实际返回片段中相关片段比例，空返回单独记录。
- 无答案识别：资料不足时是否如实说明。
- 引用正确性：人工检查建议是否被对应片段支持。
- 事实污染：是否将参考知识写成候选人经历。
- 成本与延迟：分别记录生成与 Embedding Token、总耗时与错误。

当前未内置批量 RAG 评测器；8 条求职分数回归测试不能代替 RAG 评测。

## Memory 对照实验

对相同多轮场景比较无记忆、有偏好、有偏好与摘要三种条件。
检查正确沿用、旧信息冲突、跨次污染、未授权保存和删除后遗忘。
存取成功不代表记忆语义正确，历史模型摘要需人工复核。
