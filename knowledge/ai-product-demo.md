# AI 产品经理能力与评测——合成教学资料

这是一份为 AIMatch 功能测试编写的示例知识材料，不是雇主招聘标准或真实研究结果。
来源说明：项目维护者编写的学习示例。

## 产品设计
AI 产品经理练习可以从目标用户、使用场景、主要问题、业务指标和验收条件开始。
PRD 可包含用户故事、功能边界、异常流程、数据需求和迭代优先级。
不要把功能上线或个人 Demo 自动等同于用户价值已得到验证。

## RAG 评测
检索增强生成先将知识文档分块、生成 embedding，再对查询执行向量检索。
离线评测可记录正确知识片段是否进入 Top-K、引用是否存在、回答是否获得原文支持。
无命中时应明确说明证据不足，不应给知识不存在的引用。
不同分块长度、overlap、Top-K 和阈值需要在任务数据上比较。

## Agent 与 Memory
Agent 的设计应明确状态、模型节点、工具节点、路由和终止条件。
用户确认的偏好和模型生成的摘要具有不同证据等级。
历史输出可能有错误，不能自动成为用户已完成项目或掌握能力的证明。
可用性测试、真实运行记录与失败案例分析是进一步验证产品的方法。
